**LockCenter** — это мощный LSPosed-модуль и компаньон-приложение для смартфонов **Google Pixel** (Android 15 и 16). 

Модуль решает давнюю проблему интерфейса Pixel: при появлении уведомлений однострочные часы и дата больше не прижимаются к левому краю, а выстраиваются строго **по центру экрана** вместе с компактными иконками уведомлений и карточками «Самое главное» (At a Glance).

---

## ✨ Возможности

- 🎯 **Центрирование часов и даты:** маленькие часы при уведомлениях отображаются строго по центру дисплея, а дата — на отдельной строке ровно под ними.
- 🔔 **Центрирование полки уведомлений:** свернутая круглая иконка уведомлений (Telegram, WhatsApp и др.) выравнивается ровно по центру.
- 🌙 **Идеальный Always On Display (AOD):** часы, дата и иконки уведомлений центрируются по физическим координатам экрана дисплея с автоматической компенсацией защитных смещений AOD (burn-in shift).
- ⚡ **Полная интеграция с «Самое главное» (At a Glance):** активные системные карточки (фонарик, таймер, будильник) аккуратно встают под датой и больше не перекрываются уведомлениями.
- 🎨 **Полноценное приложение с Material 3:**
  - Ползунки и прямой ввод чисел с клавиатуры для тонкой настройки каждого элемента.
  - Изменение размеров маленьких и больших часов (ширина/высота).
  - Настройка расстояний между часами, датой, фонариком и уведомлениями в пикселях.
  - Кнопка **«Применить без перезагрузки»** (передает настройки в SystemUI на лету).
  - Кнопка **«Перезагрузить SystemUI (Root)»** (мгновенный рестарт шторки за 1 секунду без перезагрузки смартфона).
- 💾 **Надёжное сохранение:** настройки хранятся в защищённой системной базе `Settings.Global` и никогда не сбрасываются при перезагрузке интерфейса или телефона.

## 🛠 Совместимость

- **Устройства:** Google Pixel (протестировано на Pixel 7 Pro `cheetah`).
- **Версии ОС:** Android 15, Android 16 (Developer Preview / Beta / QPR).
- **Требования:** Root-доступ (Magisk / KernelSU / APatch) + установленный **LSPosed** (Vector / JingMatrix).

## 🚀 Установка

1. Перейди в раздел [**Releases**](https://github.com/xlskittles/LockCenter/releases) и скачай свежий `LockCenter.apk`.
2. Установи APK на смартфон.
3. Открой **LSPosed** → перейди во вкладку **Модули** → включи **LockCenter**.
4. Убедись, что в списке приложений модуля отмечен **Интерфейс системы** (`com.android.systemui`).
5. Перезагрузи смартфон один раз для активации хуков.

## ⚙️ Настройка через приложение

После установки открой приложение **LockCenter** с рабочего стола:

| Параметр | Описание | Значение по умолчанию |
| :--- | :--- | :--- |
| **Ширина маленьких часов** | Горизонтальный масштаб цифр времени при уведомлениях | `1.60` |
| **Высота маленьких часов** | Вертикальный масштаб цифр времени | `1.30` |
| **Отступ даты от часов (px)** | Смещение даты ближе к часам или дальше вниз | `-20` px |
| **Ширина / Высота даты** | Масштаб шрифта даты | `1.30` / `1.15` |
| **Ширина / Высота больших часов** | Масштаб часов, когда уведомлений нет | `1.35` / `1.05` |
| **Отступ плашки фонарика от даты** | Расстояние между датой и карточкой «Фонарик включен» | `-50` px |
| **Отступ уведомлений от даты** | Расстояние между датой и значком/списком уведомлений | `0` px |

- Чтобы сразу увидеть результат — нажми **«Применить без перезагрузки»** или **«Перезагрузить SystemUI (Root)»**.

## 🏗 Сборка из исходников

Проект настроен на автоматическую сборку через **GitHub Actions**:

1. Сделай форк (Fork) или загрузи код в свой репозиторий.
2. Перейди во вкладку **Actions**.
3. Запусти воркфлоу **Build LockCenter APK** вручную или сделай любой коммит.
4. Готовый APK будет доступен для скачивания в блоке **Artifacts**.
