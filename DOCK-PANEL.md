# LockCenter — док-панель рабочего стола (как на iPhone)

Что добавлено в этой версии: настраиваемая полупрозрачная подложка под доком
(Pixel Launcher / Launcher3) и, по желанию, под строкой поиска рабочего стола.

Подложка **не** является отдельным окном и **не** перехватывает касания: она
рисуется внутри окна лаунчера, поэтому наследует системные анимации дока
(появление меню приложений, скрытие дока, смена сетки, поворот экрана).

---

## 1. Файлы: что менять

| Файл | Что делать |
| :--- | :--- |
| `app/src/main/java/com/anton/lockcenter/DockPanelHook.java` | **новый файл** — весь код подложки (хук лаунчера) |
| `app/src/main/java/com/anton/lockcenter/MainActivity.java` | **заменить** — добавлены настройки док-панели |
| `app/src/main/assets/xposed_init` | **заменить** — добавлена вторая строка `com.anton.lockcenter.DockPanelHook` |
| `app/src/main/res/values/arrays.xml` | **заменить** — в `xposedscope` добавлен лаунчер |
| `app/src/main/res/layout/activity_main.xml` | **заменить** — добавлены кнопки «Перезагрузить лаунчер» и «Диагностика» |
| `MainHook.java`, `build.gradle`, остальное | **не трогать** — логика экрана блокировки не изменилась |

`xposed_init` должен выглядеть так:

```
com.anton.lockcenter.MainHook
com.anton.lockcenter.DockPanelHook
```

`arrays.xml`:

```xml
<string-array name="xposedscope">
    <item>com.android.systemui</item>
    <item>com.google.android.apps.nexuslauncher</item>
    <item>com.android.launcher3</item>
</string-array>
```

## 2. Установка

1. Собрать APK (GitHub Actions или Android Studio) и установить.
2. Открыть **LSPosed → Модули → LockCenter** и убедиться, что в области действия
   (scope) отмечены **Интерфейс системы** и **Pixel Launcher
   (`com.google.android.apps.nexuslauncher`)**. После обновления модуля LSPosed
   иногда снимает галочки — проверить и включить заново.
3. Перезагрузить телефон (или хотя бы нажать «Перезагрузить лаунчер (Root)»).
4. Открыть приложение **LockCenter** — появился новый раздел
   «Док-панель рабочего стола».

---

## 3. Два режима отрисовки

| Режим | Как работает | Плюсы / минусы |
| :--- | :--- | :--- |
| **Фон дока** (по умолчанию, `dock_mode=0`) | подложка ставится фоном самой View `com.android.launcher3.Hotseat` (так делает Lawnchair) | идеально вписывается в любые анимации, минимум кода. Размер регулируется **отступами** внутрь (сделать больше самого дока нельзя) |
| **Свой слой** (`dock_mode=1`) | подложка рисуется в `DragLayer` перед его детьми, геометрия считается каждый кадр | свободная геометрия: сдвиг по вертикали, своя ширина, «мозаика» поверх родного фона. Чуть больше кода в рантайме |

Строка поиска на рабочем столе — это **ребёнок** `Hotseat` (поле `mQsb`),
поэтому в режиме «фон дока» одна подложка автоматически накрывает и док,
и строку поиска. Переключатель «Захватывать строку поиска» в этом режиме
определяет, начинается подложка выше строки поиска или ниже неё.

Если в каком-то режиме подложка не появилась — просто переключите режим и
нажмите «Применить без перезагрузки».

## 4. Настройки

Все параметры сохраняются в `Settings.Global` (`lockcenter_cfg`) и в
`lockcenter.conf` каталогов SystemUI и лаунчера, как и настройки часов.

| Параметр в приложении | Ключ | По умолчанию | Смысл |
| :--- | :--- | :--- | :--- |
| Включить подложку дока | `dock_enabled` | вкл | выключатель всей функции |
| Альтернативный режим (свой слой) | `dock_mode` | выкл | 0 — фон дока, 1 — свой слой |
| Сохранять родной фон дока | `dock_keep_original_bg` | выкл | родной фон рисуется **под** нашей подложкой (иначе заменяется) |
| Захватывать строку поиска | `dock_include_search` | вкл | подложка закрывает и строку поиска |
| Закругление подложки (px) | `dock_radius_px` | 44 | радиус скругления |
| Боковой отступ от краёв (px) | `dock_side_margin_px` | 10 | ширина подложки = ширина экрана минус 2 отступа |
| Отступ сверху (px) | `dock_top_pad_px` | 6 | запас над иконками/поиском |
| Отступ снизу (px) | `dock_bottom_pad_px` | 6 | запас под иконками |
| Сдвиг по вертикали (px) | `dock_offset_y_px` | 0 | сдвиг вверх/вниз |
| Прозрачность (0–255) | `dock_alpha` | 70 | 0 — невидимо, 255 — плотно |
| Красный / Зелёный / Синий | `dock_color_r/g/b` | 255/255/255 | цвет подложки (по умолчанию белый) |
| Размытие обоев под подложкой | `dock_frosted` | выкл | «матовое стекло» (экспериментально) |
| Сила размытия (px) | `dock_frost_radius` | 24 | чем больше, тем мягче стекло |
| Непрозрачность стекла (0–255) | `dock_frost_alpha` | 150 | плотность стекла |
| Смещение обоев по X / Y (px) | `dock_frost_offset_x/y` | 0 / 0 | подгонка, если размытый сэмпл обоев не совпал |

Подсказки по значениям:
* Классика «как на iPhone»: белый, `dock_alpha` 55–90, радиус 40–60.
* Тёмная тема: цвет 20/20/20, `dock_alpha` 90–140.
* «Стекло»: включить `dock_frosted`, `dock_frost_radius` 20–30,
  `dock_frost_alpha` 120–170.

## 5. Проверка и диагностика

Кнопка **«Диагностика: дамп лаунчера в лог»** отправляет в процесс лаунчера
запрос, и модуль печатает в лог LSPosed (фильтр `LockCenter`) всё дерево View:
классы, id, размеры, position, translation, scale, положение в окне и
кандидатов в «строку поиска».

Что смотреть в логе **LSPosed → Журнал** (фильтр `LockCenter/Dock`):

```
[LockCenter/Dock] модуль активен в com.google.android.apps.nexuslauncher, Hotseat = com.android.launcher3.Hotseat
[LockCenter/Dock] настройки: режим=фон дока ...
[LockCenter/Dock] фон дока применён: insets=10/6/10/6 radius=44 color=255,255,255/70 frost=false (родной фон заменён)
[LockCenter/Dock] подложка привязана: container=com.android.launcher3.dragndrop.DragLayer hotseat=com.android.launcher3.Hotseat
[LockCenter/Dock] строка поиска найдена: com.android.launcher3.qsb.QsbContainerView#search_container_hotseat [912x160]
```

Если строки `фон дока применён` нет — модуль не активирован для лаунчера
(проверьте scope и перезагрузите телефон).

## 6. Известные ограничения

* **Настоящий backdrop-blur окна лаунчера недоступен**: `View.setBackgroundBlurRadius`
  в публичном API не существует, `WindowManager.LayoutParams.setBlurBehindRadius`
  размыл бы весь экран за окном (лаунчер — полноэкранное не-ploating окно), а
  `Window.setBackgroundBlurRadius` требует translucent+floating окно.
  Поэтому «матовое стекло» сделано сэмплом размытых обоев: под доком видно
  именно обои, поэтому визуально совпадает. Если обои — live wallpaper или
  сильно смещены параллаксом, сэмпл может не совпасть: подстройте
  «Смещение обоев по X/Y» или выключите стекло.
* В режиме «фон дока» подложка не может быть больше самого дока (Hotseat):
  регулируется только внутрь (отступами). Нужна свободная геометрия —
  включите «свой слой».
* `Hotseat.resetLayout()` (смена сетки, поворот, изменение DPI) пересоздаёт
  содержимое дока — фон применяется повторно автоматически (хук `resetLayout`
  + проверка каждого кадра), но если что-то «слетит» — нажмите
  «Применить без перезагрузки».
* Настройки проверяются хуком раз в 4 секунды и мгновенно по кнопке
  «Применить без перезагрузки».

## 7. Быстрый чек-лист, если подложки не видно

1. LSPosed → Модули: LockCenter включён, в scope отмечен **Pixel Launcher**.
2. «Перезагрузить лаунчер (Root)» (или перезагрузка телефона).
3. `dock_enabled` = вкл, `dock_alpha` = 200 (проверить, что дело не в прозрачности).
4. Переключить «Альтернативный режим (свой слой)» + «Применить без перезагрузки».
5. Нажать «Диагностика: дамп лаунчера в лог» и посмотреть лог LSPosed —
   там видно, нашёлся ли `Hotseat` и `mQsb`, и какие у них размеры.
